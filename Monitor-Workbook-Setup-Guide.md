>Workbook instructions
  1. Open the workbook json template file from this repo into Notepad and replace all 3 fields with your tenant values:

     | `{subscriptionID}` | `{resourceGroup}` | `{workspaceName}` |
     |--------------------|-------------------|-------------------|
   
  2. Save your JSON file and upload it to the repo for future use.
  
  3. Go to `Azure Portal` > Search for `Monitor` and navigate to it.
  
  4. Click `Workbooks` and then click `New`.
  
  5. Click `</>` (Advanced Editor) and then replace the displayed JSON text with your updated JSON text.
  
  6. Click `Apply` and `Save`. <br/>
